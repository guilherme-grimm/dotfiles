# Global agent instructions

## Pull request sizing

- **Doc changes** (README, ADRs, CONTRIBUTING, comments, roadmap docs): flexible — no line limit.
- **Code changes**: target **~400 lines** of diff, **500 lines hard cap**. If a change can't fit, split it into stacked PRs by concern (e.g., rename pass, then schema pass, then behavior pass). Applies to every project.
